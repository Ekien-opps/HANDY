# Animation du logo Marin'Or Ivoire (After Effects)

1. Téléchargez tout ce dossier (le script + les PNG).
2. Dans After Effects : **Fichier > Scripts > Exécuter le fichier de script...** puis choisissez `MarinOr_Ivoire_LogoAnim.jsx`.
3. Le script trouve les PNG à côté de lui. Sinon, il vous demande le dossier qui les contient.

Résultat : une composition 1920×1080, 60 i/s, 5 s, déjà animée et lissée.

- Les **durées** se règlent dans le bloc `TIMING` en haut du script.
- La **taille et la position du logo** se règlent dans `CONFIG`, et la position des pièces dans `LAYOUT`.
- Dans After Effects, les marqueurs de composition repèrent les 3 séquences.

`apercu_animatique.mp4` et `apercu_planche.png` sont un **aperçu approximatif** calculé hors d'After Effects, sans flou de mouvement. Ils servent seulement à vérifier le timing et les cadrages.

La direction sonore est dans [`../DIRECTION_SONORE.md`](../DIRECTION_SONORE.md).
